## 结论先说

**上一轮我说错了一件事**：dsh-go 的「主机」里**没有**"手填一个 HTTP 地址"的入口。它只有三条连接路径：

| 路径 | 要什么 | 能不能直接指向别人的 host |
|---|---|---|
| 本机 | App 自己在 proot 里起 `dsh web`，读它的 stdout | 不能（启动命令是 manifest 里的数据） |
| DSH Remote | liguobao 的 relay + 账号（GitHub/知乎/Google/邮箱） | 不能（没有账号体系） |
| SSH 主机 | 一台开 SSH 的机器，两种模式：**托管启动** / **只连接** | **能** ← 唯一的手动入口 |

所以「官方 APK 直连 codex 移动端」这条路的正解是 **SSH**，不是填 URL。这点必须在方案里写死。

   `open_connection('127.0.0.1',3090)` → `GET /?token=dev` → **`HTTP/1.1 303 See Other` + `set-cookie`**

## 从源码挖到的「SSH 主机」真实协议（这轮最重要的产出）

`app/lib/remote/ssh/remote_bootstrap.dart` 里 App 在远端执行一段 shell，靠带前缀的行回报状态：

```
DSHAPP home <HOME>          # 远端 home
DSHAPP dsh <path>           # dsh 在哪
DSHAPP started <pid>        # 起了进程
DSHAPP url <http://127.0.0.1:PORT/?token=…>   # ← 真正要的那一行
DSHAPP shared               # 已有可复用实例（exit 73）
DSHAPP nodir                # 没有实例/目录
DSHAPP opened <path>        # 直接打开了一个路径
DSHAPP exited / timeout / log <line>
```

**只要有一台机器会对 `exec` 回这几行，App 就会把端口经 SSH 隧道转过来并用给定 token 登录。**
换句话说：`codex-bridge` 只要冒充这套 `DSHAPP` 输出 + 说 DSH 协议，官方 App 就能用它 —— 不需要改 APK。

- 托管启动模式执行的命令：`<launchCommand> --host 127.0.0.1 --port 0 --no-open`（默认 `launchCommand = dsh web`）
- 只连接模式：不执行命令，只要 `remotePort` + `attachToken`，然后隧道直连

`device/ssh-forward.py` 就是按这个协议写的最小 SSH 服务器（密码认证 + direct-tcpip + `DSHAPP` 应答），用来替代"开 OpenSSH Server"。

## 输入这件小事（踩了很久）

- `adb shell input text` 走系统输入法：**中文输入法会把 `codex` 变成拼音候选**（真机上出现过「熬得住」）
- ADBKeyboard（`com.android.adbkeyboard`，机器上已装）在 Android 16 上**广播没生效**（`ADB_INPUT_TEXT` / `ADB_INPUT_B64` 都没写进 Flutter TextField）
- 最后可行的：**纯数字**用 `input text`（不过输入法），并且 **tap 输入框后立刻 `input text`**，不要等布局重排
- 所以在真机上做实验时，密码/端口/token 全用数字（本机 ssh 密码改成 `123456`，token 用 `dev` 走代码注入）

## 复现命令

```powershell
# 1) 起 dsh-host（冒充 dsh web 的那层）
cd codex-go
node dsh-host\server.mjs --backend fake --port 3090 --token dev

# 2) 起 SSH（替代 OpenSSH Server；密码 123456，host key 固定）
python device\ssh-forward.py --port 2222 --target 3090 --password 123456

# 3) 端口反向映射，让手机 127.0.0.1 能打到电脑
adb reverse tcp:3090 tcp:3090
adb reverse tcp:2222 tcp:2222

# 4) App：切换主机 → 连接电脑或服务器 → 添加 SSH 主机
#    名称 codex-go / 主机 127.0.0.1 / 端口 2222 / 用户 dev / 密码 123456
#    实例管理：托管启动（launchCommand 保持 dsh web）或 只连接（远端端口 3090 + 令牌 dev）
#    点「测试连接」→ 确认指纹 → 保存 → 连接
```

   `Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0; Start-Service sshd`
   然后 App 直接连 22，托管启动模式下把 launchCommand 换成能打印 `DSHAPP url` 的脚本。
2. **继续磨 asyncssh 的认证**（不用管理员）：先 `set_debug_level(1)` 看 App 发的 kex/auth 包，多半是 `password_auth_supported` 之外的算法协商（dartssh2 可能先试 `none`/`publickey`）。
3. **跳过 SSH**：用 Reload/relay 账号，或改 APK 把 host 预置进 `hosts` 存储（要重打包）。
